# v1.1.2 · 实验进度与合并审核修复

发布日期：2026-10-09。

实验进度以最后一个有有效值、备注、附件或已勾选条目的步骤为准。浏览位置、自动开始时间、空字段和纯空白文字不增加进度；零值仍是有效记录。主页、实验页、日历和待办使用同一判定，输入后局部刷新进度，不重建表单。没有填写的实验显示“尚未记录”，移除手动将浏览位置设置为进度的入口。Word 导出按实际记录边界，并保留已有完成事实。

合并审核允许后续步骤仅有空字段和自动开始时间的实验通过“无后续记录”检查。实际值、备注、附件、已勾选项、完成状态和结束时间仍会阻止合并；异常非空历史勾选数据保持保守保护。全部前置和后置步骤定义、顺序、字段和单位仍须匹配，前置步骤仍须全部完成。
