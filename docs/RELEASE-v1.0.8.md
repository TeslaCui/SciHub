# v1.0.8 · 实验方案交互

发布日期：2026-10-08。

主页和方案列表的方案卡片支持右键菜单、手机长按及 Shift+F10。菜单提供重命名和删除，支持方向键、Escape、点击外部关闭及屏幕边缘定位。滑动会取消长按；长按松手不会打开预览。重命名与删除确认使用软件弹层。详情页移除重命名入口。保存新建或编辑方案后进入方案预览；取消已有方案编辑返回原预览，取消新建返回列表。

## 数据兼容

本次不修改数据库结构、迁移文件或既有实验同步规则。旧方案继续通过原表和接口读取、编辑；重命名只更新账号所属的目标方案名称。删除只在用户确认后按方案 ID 和账号 UUID 提交。既有外键会删除方案步骤，并解除实验的方案引用；执行步骤、实测值、备注和附件引用仍归属于原实验。方案若仍关联已合并的只读支路，数据库现有触发器会拒绝整笔删除，原数据保留。

- 54 项自动回归全部通过，包括三个菜单手势测试、隔离 PostgreSQL 的事务/RLS/合并保护及 Edge Function TypeScript 检查。
