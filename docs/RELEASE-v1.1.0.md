# v1.1.0 · 页面导航

发布日期：2026-10-08。

主页、方案列表、方案预览与编辑、实验、科研记录与编辑表单、教程支持浏览器后退和前进。软件图标可返回主页；所有站内页面复用固定顶部栏，包括工具和已登录账号菜单。教程在当前标签打开；旧教程链接和流程锚点仍可访问。教程样式限定在内容区域内。

切页等待科研记录和实验保存，保存失败时保留原页面并恢复浏览器位置。方案草稿和记录表单在当前页面会话中保留，后退或前进可以恢复；刷新、退出登录或关闭标签前仍须保存。保存或取消编辑后使用原有返回流程，已完成编辑的旧历史入口不会恢复已丢弃的方案草稿。过期的异步方案加载或导入结果不能覆盖较新的导航。

## 数据兼容

本次无数据库迁移、结构修改或旧数据转换。既有方案、实验快照、字段、实测零值、备注和附件引用沿用原表和接口。浏览器历史只保存导航序号和页面地址，不存入科研内容或凭据。没有将主工作区尚未发布的方案更新审核改动混入本次提交。

- 独立本地模拟来源验证主页、方案预览与编辑、草稿恢复、保存返回预览、实验切页保存、零值与备注刷新保留、科研记录新建/编辑/刷新、教程搜索、语言、流程链接、工具及账号菜单、退出和重新登录。
- 390px 视口验证手机教程无整体横向溢出，目录横向滚动，流程定位和顶部栏固定。实体手机未测试。
- 网站和 GitHub 教程由同一源生成，新增页面导航流程，共 54 个双语流程。旧 `guide.html` 链接在本地验证进入同一软件外壳并保留流程锚点。

本轮未使用生产内测账号写入，没有操作真实用户科研记录或附件。本地删除提示验证时，浏览器工具直接确认了原生确认框，误删刚创建的虚构记录“[内测]页面导航回归 1.1.0”；已重新创建同标题、日期和内容的模拟记录，记录 ID 为新建 ID。后续停止原生删除框验证。模拟测试数据及截图保留在仓库外，未自动删除文件或清理工作区。
