# 专用内测账号与测试隔离

用户已授权创建一个普通内测账号，用于后续功能测试。账号属于 SciHub 的 Supabase 项目 `ttjnxndmjwhwpamyeuva`。账号 ID、邮箱、密码及测试记录清单仅保存在仓库外的本机私密配置中；本文件不发布这些信息。

## 开始测试

1. 本机配置位于 `%LOCALAPPDATA%\SciHub\beta-testing\account.dpapi`；使用同目录的 `account-tools.cjs` 读取，密码由 Windows 当前用户的 DPAPI 加密。目录仅授予当前 Windows 用户与 SYSTEM 访问。先核对配置中的项目、账号 ID 和测试用途。换电脑或换 Windows 用户后不能假定仍可解密。脚本只供本机维护，不进入网站资源。
2. 使用独立浏览器上下文，或专用本地测试来源（例如 `http://127.0.0.1:8788/`，不加 `mock=1` 时连接真实服务）。先确认该来源没有正常用户的会话，禁止覆盖正常用户的登录状态。通过认证接口取得当前账号，核对返回的 UUID 与私密配置一致，再打开测试功能；页面用户名也须与配置一致。
3. 所有测试内容使用虚构实验，标题加 `[内测]`。只查询该账号行；更新条件同时包含账号 UUID 和已确认的记录 ID。上传附件前核对路径以该 UUID 开头。
4. 新建、编辑、重新加载后核对数据和归属；记录测试时间、版本、功能、结果及限制。用记录 ID 区分既有测试数据，避免重复测试时误改此前的样例。
5. 账号不符、凭据缺失、RLS 拒绝或项目不符时停止写入，保留现场。不得改用正常用户账号或管理员令牌继续测试。

## 密码与邮箱

凭据不得提交到 Git，也不得写入公开网页、截图、日志或聊天输出。密码只能由当前 Windows 用户在本机私密存储中解密使用。

若使用保留域名 `example.invalid` 的邮箱，它没有可接收邮件的邮箱，无法邮件验证或找回密码。注册前须确认当前项目无需邮件确认；以后认证策略改变时停止测试，先配置用户控制的测试邮箱。不得以关闭确认、修改所有用户认证设置或降低权限检查作为替代。

## 隔离范围

生产内测账号依赖既有 RLS 隔离账号数据，不等于独立测试数据库。迁移会修改共享结构，测试上传与 AI 调用也会使用项目配额。因此迁移、数据转换、失败回滚、重复执行、并发及多账号 RLS 测试优先使用本机隔离数据库和虚构夹具；通过后再做少量线上内测验证。

内测账号不应读取正常用户的数据来证明隔离。跨账号拒绝验证使用隔离环境中的两个虚构账号。保留历史记录和附件，不能自动清空内测账号；任何删除仍须列明对象、原因并取得用户授权。
