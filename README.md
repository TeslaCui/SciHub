# SciHub 科研知识工作台

一个本地优先的科研工作台。它把 **AI 对话** 与 **可复用的知识卡片** 分开管理，并用明确的验证状态提示用户：AI 输出不是已确认的科研事实。

在此基础上集成了 **实验日志、对话记录与项目记忆** 三大模块——它们会把内容保存成人类可读的 Markdown 文件，并为每个项目实时维护一份 `AGENTS.md`，可直接交给 AI 作为项目记忆继续提问。

## 快速开始

双击 **「启动 SciHub.cmd」**（Windows）。脚本会用 Python 启动本地服务，并自动打开工作台。保持窗口开启即保持服务运行，关闭窗口即停止。

手动启动：

```bash
python scihub_server.py
# 然后浏览器访问 http://127.0.0.1:8770/index.html
```

要求：本机安装 **Python 3**（Windows 安装时请勾选 “Add Python to PATH”）。除 Python 标准库外，**无需任何第三方依赖**。

## 数据保存在哪里

| 内容 | 存储位置 | 格式 |
| --- | --- | --- |
| 项目、实验日志、对话记录、项目记忆 | 本文件夹下的 `科研项目/<项目>/` | Markdown（`.md`）|
| 知识卡片、概览页 | 当前浏览器的 `localStorage` | 浏览器本地 |
| AI 接口地址 / 模型 / API Key | 当前浏览器的 `localStorage` | 浏览器本地 |

每个项目的目录结构：

```
科研项目/<项目名-时间戳>/
├── README.md          # 项目说明与重要信息（含 front-matter 元数据）
├── AGENTS.md          # 项目记忆：自动区块随日志/对话实时更新，可交给 AI
├── 实验日志/
│   └── 2026-07-26.md  # 按日期保存：原始记录 / 实验现象 / 实验记录
└── 对话记录/
    └── c-xxxxx.md     # 每段对话一份，保留 user / assistant 消息
```

`科研项目/` 已在 `.gitignore` 中排除，你的实验数据不会被提交到版本库。

## 功能

**实验日志**：按日期记录原始实验记录，可选调用 AI 把原文整理成「实验现象 / 实验记录」（不编造数据，采用前可手改）。支持自动保存与 `Ctrl/⌘ + S`。

**对话记录**：在项目下新建、手工记录或导入外部对话；配置 AI 后，可把该项目的 `AGENTS.md` 作为上下文继续提问，回答与记忆一并保存。

**项目记忆**：维护项目说明与重要信息，写入 `README.md` 与 `AGENTS.md`；`AGENTS.md` 中自动区块之外的手工内容会被保留。

**知识卡片 / 概览**（原有能力）：对话消息可沉淀为知识卡片；按项目/类型/状态/关键词筛选；明确的「未核验 / 待验证 / 已验证 / 存疑」状态。

## 隐私与网络

服务仅监听回环地址 `127.0.0.1`，不会把项目文件上传到网络。只有当你在「对话记录」里点击发送、且已在「AI 设置」中配置接口时，对应消息才会经本机服务转发到 **你自己配置的 HTTPS 模型接口**（用于绕过浏览器 CORS 限制）。API Key 仅保存在本浏览器。

## 技术形态

纯 HTML / CSS / JS 前端（无构建、无 CDN）＋ Python 标准库 HTTP 服务（`http.server`）。三个前端文件：`index.html`、`app.js`（知识卡片/概览）、`records.js`（文件后端集成层，`window.SciHubRecords`）。
