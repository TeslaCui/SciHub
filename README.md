# SciHub 科研记录工作台

SciHub 是一个本地优先的科研记录工具，只保留三项核心能力：

- **实验日志**：按日期保存实验过程、观察和结论草稿。
- **对话记录**：新建、手动整理或导入各类 AI 对话，并可携带项目记忆继续提问。
- **项目记忆**：维护项目说明和关键信息，供后续检索或交给 AI 作为上下文。

所有项目资料都保存为可直接阅读和编辑的 Markdown 文件；不会创建专有数据库或锁定你的数据。

## 启动

在 Windows 中双击 [启动 SciHub.cmd](启动%20SciHub.cmd)。脚本会使用本机 Python 启动服务，并打开：

`http://127.0.0.1:8770/index.html`

保持命令窗口开启即可继续使用；关闭窗口会停止服务。

也可以在此目录手动运行：

```powershell
& 'D:\LeStoreDownload\Anaconda\python.exe' .\scihub_server.py
```

SciHub 只使用 Python 标准库，不需要安装额外依赖。

## 使用方式

1. 点击“新建项目”，填写项目名称与说明。
2. 在“实验日志”中记录当天实验；保存后会写入项目的 `实验日志/日期.md`。
3. 在“对话记录”中新建、手动整理或导入 AI 对话；每段对话单独保存为 Markdown。
4. 在“项目记忆”中维护项目说明和重要信息。系统会同步更新 `README.md` 与 `AGENTS.md`。
5. 在“AI 设置”中填入你自己的兼容接口后，可把项目 `AGENTS.md` 作为上下文继续对话。

## 文件结构

每个项目位于 `科研项目/<项目名称>/`：

```text
科研项目/<项目名称>/
├── README.md          # 项目说明与重要信息
├── AGENTS.md          # 可提供给 AI 的项目记忆
├── 实验日志/
│   └── YYYY-MM-DD.md  # 按日期保存的实验日志
└── 对话记录/
    └── c-*.md         # 每段导入或新建的对话
```

`AGENTS.md` 的自动更新区域会随日志、对话和项目记忆的保存而刷新；自动区域外的手动内容会被保留。

## 隐私

服务只监听本机地址 `127.0.0.1`。只有当你主动发送消息并配置 AI 接口时，SciHub 才会将该次消息转发到你指定的 HTTPS 模型接口。API Key 仅保存在当前浏览器的本地存储中。
